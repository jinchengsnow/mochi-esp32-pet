# MOCHI 0.7.0 验证记录 — 2026-10-30

启动日志从应用描述读取真实版本号，避免旧提示与镜像版本不一致。

本版增加UTC+8日历作息、每天小幅变化的入睡/起床/午休、10分钟临时叫醒、可点击的顶部时钟和日期/小时/分钟校准，以及四种白天亮屏待机动画。保留0.6.0触控互动、低功耗、明暗6倍率、电量和v3存档兼容。

## 软件验证

- ESP-IDF5.5.5 / ESP32-S3构建通过，最终构建日志无warning/error。应用809,904字节，6MiB应用分区剩余87%。esptool显示版本0.7.0，checksum和validation hash有效。
- ASan/UBSan的7组测试全部通过，新增作息测试连续检查400天：21:45–22:15入睡、07:00–08:00起床、13:00–13:15午休开始、13:45–14:00结束；同日稳定、跨日波动，起止分钟边界和午夜归属正确。
- 未校时不启动日历睡眠；亮屏不再60秒闲置自动睡觉。夜间临时叫醒期限、期限结束继续睡、校时跳变清除旧期限、日间手动睡眠和起床边界通过。
- 到入睡点不打断吃饭或游戏；游戏只结算一次。熄屏期间按日历更新角色，作息变为白天时不打开显示和触摸，仍由PWR恢复。
- 四种待机姿态均实际变化，计时回绕、活动结束、不连续重复，以及菜单/输入/夜间/熄屏禁用通过。自主活动不记摸摸奖励、不发星星或心愿进度。
- 真实LVGL指针事件验证日期+、小时−、分钟+和保存，按保存时间立即进入正确午休状态；校时不改变成长。检查正常电量和低电量顶栏的时钟边界，文字不重叠、不被父对象裁切。
- 原有手势、喂食、小游戏/心愿/商店、十级形象和装扮、v1/v2迁移及v3存档、明暗时间补算、PWR和熄屏禁用触摸回归通过。
- 340个UI字符通过glyph lookup，无占位符。生产LVGL绘图代码渲染415帧，包含夜间、清晨、午休、午后、时钟校准和4段各4秒的待机动画。主机夹具构造时钟、电池和输入，没有向固件注入预绘制图片。
