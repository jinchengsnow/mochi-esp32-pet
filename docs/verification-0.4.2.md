# MOCHI 0.4.2 验证记录 — 2026-10-29

本版本增加AXP2101电池百分比/充电状态、低于10%标注、主页熄屏按钮和触摸唤醒。宠物存档格式和等级形象保持兼容。

## 已完成的软件验证

- ESP-IDF5.5.5 / ESP32-S3构建通过，最终编译无warning/error。应用775,216字节，6MiB应用分区剩余88%；esptool checksum和validation hash有效。
- 电池解码在ASan/UBSan下通过：0/9/10/100、充电与USB状态、电池缺失、电量计未启用、非法101/255读数，以及读取不可用。低电量判断严格使用 `< 10`。
- 真实LVGL指针事件验证：正常/低电/10%边界/充电中/未装电池/读取失败文案、熄屏全黑、亮屏、首次触摸不穿透、独立二次喂食、熄屏与唤醒接口失败后保留状态并重试。
- 原有模型/存档测试和界面集成回归通过，包含游戏、心愿、商店、旧存档迁移、10级形象、各状态动画与装扮适配。
- 273个UI字符通过LVGL glyph lookup，无占位符。生产界面代码渲染240帧；实际查看 `preview/power-overview.png`，顶栏电量、熄屏按钮、底部存档状态和低电量标注显示正常。

日志：`build-verification-0.4.2.log`、`model-verification-0.4.2.log`、`preview-verification-0.4.2.log`、`image-info-0.4.2.txt`。电量夹具在主机上模拟，固件使用 `pet_device.c` 读取实际芯片。0.4.1记录保留在 `verification-0.4.1.md`。
