# MOCHI 0.6.0 验证记录 — 2026-10-30

本版增加单击摸头、双击玩耍、三击挠肚皮、长按抱抱、左右滑动逗猫和上滑击掌。保留0.5.0的低功耗、明暗速率、PWR、触摸禁用、电量和存档兼容逻辑。

## 软件验证

- ESP-IDF5.5.5 / ESP32-S3构建通过，最终日志无编译warning/error。应用797,248字节，6MiB应用分区剩余87%；esptool checksum和validation hash有效。
- ASan/UBSan手势识别测试通过：单/双/三击、精确320ms间隔边界、四击尾部抑制、650ms长按边界、松手后不补发、左右/上滑、下滑/对角线/往返拖动排除、取消与32位tick回绕。
- 表情模型测试通过：各动作使用不同姿态参数，共享摸摸成长冷却和心愿进度；动画参数有限且在预期范围；进食、游戏中和熄屏时拒绝亲昵动作。
- 真实LVGL指针事件验证七种手势场景。单击延迟前不奖励，双击只入场扣5饱食且没有摸摸成长，三击不进入游戏，长按释放不重复奖励，切换亲昵手势不额外发成长。
- 喂食、成长页和PWR切换取消待判定手势；熄屏触摸无操作、亮屏按住保护继续通过。
- 原有游戏/心愿/商店、v1/v2迁移及v3存档、低功耗补算与明暗6倍率、十级形象及装扮检查通过。
- 299个UI字符通过glyph lookup，无占位符。渲染250帧，实际查看最终 `preview/touch-overview.png`，不同动作、方向注视、举爪、抱抱及中文反馈正常。图来自生产绘图代码，状态和输入由主机夹具构造。

日志：`build-verification-0.6.0.log`、`model-verification-0.6.0.log`、`preview-verification-0.6.0.log`、`image-info-0.6.0.txt`。此前0.5.0记录保留在 `verification-0.5.0.md`。

## 实机范围

0.6.0尚未在本次烧录实机。实际手指连击节奏、长按阈值、滑动距离及边界手势需在触摸屏上确认。低功耗电流/续航和真实睡眠恢复仍沿用0.5.0的待验收范围，不能用主机动画预览代替。此次不改变v3存档格式和烧录分区映射。
