# MOCHI 0.4.3 验证记录 — 2026-10-29

本版移除屏幕熄屏按钮，改为PWR物理短按切换显示，熄屏期间禁用触摸，并加入电量填充图标与充电闪电。宠物存档和成长规则保持兼容。

## 已完成的软件验证

- ESP-IDF5.5.5 / ESP32-S3构建通过，最终编译无warning/error。应用776,592字节，6MiB应用分区剩余88%；esptool checksum和validation hash有效。
- ASan/UBSan按键协议测试通过：0x41只增加短按使能，0x49只确认短按位，启动遗留事件丢弃、同一锁存事件只投递一次、长按不切换屏幕、读取和确认失败不产生事件并可重试。
- 真实LVGL指针事件验证：无屏幕熄屏按钮；物理键熄屏/亮屏；熄屏时指针读取计数不增加；点角色、喂食和原按钮位置均不唤醒或改变成长/饱食；亮屏时手指仍按住不触发操作，松开后新的点击可正常喂食。
- 物理键显示接口失败时保留原状态并可再次短按重试；成长页和游戏中可熄屏/亮屏，熄屏期间无法点菜单或命中星星。
- 电量0/9/10/100、USB/充电、未装电池、未启用电量计和非法读数单元测试通过。低电量标注严格使用 `< 10`。
- 原有模型、存档和UI回归通过，包含游戏结算、心愿、商店、旧存档迁移、10级形象和装扮适配。
- 273个UI字符通过glyph lookup，无占位符；生产绘图代码渲染240帧，实际查看 `preview/power-overview.png`，电量图标、填充、闪电、低电量提示及移除按钮后的布局正常。

日志：`build-verification-0.4.3.log`、`model-verification-0.4.3.log`、`preview-verification-0.4.3.log`、`image-info-0.4.3.txt`。上一版记录保留在 `verification-0.4.2.md`。

## 实机范围

0.4.3尚未烧录实机。主机物理键事件、寄存器和电量使用夹具；需设备验证PWR短按上报、熄屏/亮屏、触摸完全无操作及亮屏后松手保护，以及实际电量和功耗。

固件仅增加PWR短按中断使能并确认该状态位，不改变长按关机、充电参数或供电轨。熄屏期间CPU计时与后台存档继续；尚未进入ESP32低功耗睡眠。发行包仍仅写启动器、分区表和应用，不包含宠物NVS。
