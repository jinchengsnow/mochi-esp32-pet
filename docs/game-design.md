# MOCHI 口袋伙伴：养成游戏设计

当前版本：0.8.1。设备：Waveshare ESP32-S3-Touch-AMOLED-1.75C。

MOCHI 是一只住在圆屏里的小猫。每次拿起设备，玩家都能通过照顾、短局游戏和装扮做出可见改变；放下设备后也不会因为疏于照顾而失去宠物。核心循环为：**观察需求 → 摸摸或喂食 → 挑战追星星 → 获得成长和星星 → 完成陪伴心愿 → 解锁外观 → 再次陪伴。**

本文定义当前玩法和边界；编译、主机测试及实机验证结果以相应版本的验证记录为准。

## 一次游玩如何展开

首次打开时，小猫的饱食为 70。玩家点击小猫获得开心反馈和 1 点成长，再喂食获得 25 饱食和 4 点成长。吃饭结束后，进入一局 15 秒的“追星星”：追着亮起的星星点击，位置每次改变，连续命中会形成连击。

命中 5 次即可获得 3 成长和 2 星星，命中 10 次可获得 6 成长和 4 星星。此前的摸摸和喂食，加上这次合格游戏，组成第一轮陪伴心愿，自动再奖励 6 成长和 5 星星。首次完整循环因此可达到 14 或 17 成长，接近少年阶段的 20 点门槛。

之后可查看成长页和装扮目标。小游戏冷却 60 秒，玩家可以继续摸摸、观察表情、切换已拥有的装扮，或暂时放下设备。达到少年阶段后，第一件蝴蝶结就成为具体、可理解的消费目标。

## 圆屏交互

| 操作 | 反馈与用途 |
|---|---|
| 单击/双击/三击小猫 | 摸头 / 追星小游戏 / 挠肚皮 |
| 长按/左右滑/上滑 | 抱抱 / 逗猫 / 击掌；亲昵动作共用陪伴奖励冷却 |
| 点击底部“喂食” | 检查饱食；有效喂食立即结算，随后播放吃饭动画 |
| 点击底部“追星” | 开始追星星；冷却中或饱食不足时给出原因 |
| 点击底部“睡觉 / 叫醒” | 切换角色睡眠；睡眠状态也可通过摸摸唤醒 |
| 短按物理BOOT键 | 切换互动声音，保存静音偏好；不亮灭屏幕 |
| 点击顶部时间 / 校时 | 设置北京时间，开启日历作息 |
| 点击顶部名称 | 打开成长、陪伴心愿和装扮页面 |
| 在小游戏中点击亮起的目标 | 命中计数、连击反馈和目标换位 |
| 退出小游戏 | 中止本局，进入冷却，不发放本局奖励 |

主界面把角色放在中心，底部保留三个主要操作。进阶信息放到成长页，避免在 1.75 英寸圆屏上堆叠细小按钮。所有关键操作应有中文反馈，并区分“动画回应”和“本次获得奖励”。

详细手势判定与奖励见 [触控互动](touch-interactions.md)。夜间睡眠、午休和白天待机见 [作息与待机](routine.md)：约22点入睡、7–8点起床，13–14点内午休；每天小幅变化。亮屏白天不再闲置60秒就睡，改为伸懒腰、洗脸、毛线球和蝴蝶待机。

## 照顾与成长规则

| 系统 | 当前规则 |
|---|---|
| 饱食 | 0–100；亮屏每5分钟−1、熄屏每30分钟−1；整机关机暂停；不会饿死 |
| 喂食 | 饱食不高于 75 时可用；增加 25 饱食和 4 成长；吃饭中不能重复结算 |
| 摸摸 | 每次可有动画回应；首次获得 1 成长，此后每累计开机 5 分钟最多再获得一次 |
| 幼崽 | 成长 0–19 |
| 少年 | 成长 20–59；获得阶段外观变化，开放蝴蝶结购买 |
| 成年 | 成长不低于 60；获得阶段外观变化，开放皇冠购买 |
| 羁绊等级 | `min(10, 1 + 成长 / 60)`，整数除法；60 成长为 2 级，540 为 10 级 |
| 自然成长 | 亮屏每10分钟+1、熄屏每60分钟+1，互动奖励另计 |
| 成长上限 | 600；成年后仍可继续积累；不因饥饿、退出游戏或离线降低 |
| 星星 | 游戏和心愿产出，用于购买永久装扮；上限 9,999 |

成长阶段表示小猫长大，羁绊等级表示持续陪伴的积累。当前版本还会随羁绊等级逐级改变体型、毛色、花纹和毛量；完整映射见 [形象设定](appearance.md)。阶段与装扮继续提供外观奖励；羁绊等级不额外提供隐藏属性或小游戏加成。

## 追星星：15 秒触摸小游戏

场上设置五个固定目标位置，每次只亮起一个。玩家需要看到新位置，再点击目标；命中后目标按 `(当前编号 + 2) % 5` 换位。位置规则固定，玩家可以通过练习熟悉节奏。点错会中断连击，已经获得的命中次数仍保留。

- 开始条件：当前没有吃饭或进行中的游戏，游戏冷却为零，饱食至少为 10。
- 入场消耗：立即扣除 5 饱食，退出也不退回。
- 防止重复触发：两次有效命中至少间隔 180 毫秒。
- 时长：15 秒，到时只结算一次；超时点击不计分。
- 命中 0–4 次：本局无成长和星星奖励。
- 命中 5–9 次：奖励 3 成长、2 星星。
- 命中至少 10 次：奖励 6 成长、4 星星。
- 连击用于即时反馈和成绩展示；当前奖励依据总命中次数。
- 完成或主动退出后，冷却 60 秒；剩余冷却随存档保留，关机期间暂停。

目标换位要求持续观察和操作，单局上限让一次拿起设备即可完成挑战。游戏进行中不触发自动睡眠；普通照顾操作不能与本局交叉结算。开局预留75秒倒计时并请求保存，包含本局15秒和随后60秒；中途重启按最近成功存档的剩余倒计时恢复。进行中的一局属于临时状态，重新启动后不续局，也不补发未结算的奖励。

## 陪伴心愿：鼓励多种互动

每轮心愿需要完成三件事：

1. 一次真正获得摸摸奖励的陪伴。
2. 一次有效喂食。
3. 一局至少命中 5 次的追星星。

顺序不限，完成情况写入存档。每项每轮只记一次；再次完成同一项不会叠加该项进度。三项齐全时，自动发放 **6 成长和 5 星星**，然后开启下一轮。触发完成的这次操作归属刚结束的一轮，不再次计入新一轮。

心愿按轮次重复，没有每日刷新、连续签到或过期惩罚。日历校时只用于作息；所有奖励冷却仍以实际开机经过的时间计算，修改日期不刷新奖励。有效喂食和摸摸冷却也让每轮心愿需要持续陪伴，无法通过连续点击三个按钮无限领取。

## 装扮与奖励

| 装扮 | 解锁条件 | 首次花费 | 拥有之后 |
|---|---|---|---|
| 不佩戴装扮 | 无 | 免费 | 随时切换 |
| 蝴蝶结 | 成长至少 20 | 8 星星 | 永久拥有，免费装备 |
| 皇冠 | 成长至少 60 | 16 星星 | 永久拥有，免费装备 |

同一时间佩戴一件装扮。购买同时装备；再次点击已经拥有的装扮不会重复扣费。星星不足或成长不足时，应保留现有装扮并明确提示条件。装扮不提高成长效率，玩家可以按自己的喜好选择。

## 互动声音

有效互动发出对应的短喵音、呼噜感音效、咀嚼或提示音；没有获得成长时仍可回应，但被忙碌状态拒绝的动作不发声。BOOT键切换声音并记住偏好。音效与奖励独立，不增加成长或星星。只有显式照顾、游戏和换装触发音效；自主待机和作息变化保持安静。详见 [声音说明](sound.md)。

## 电量和屏幕

主页提供电池图标和电量百分比。低于10%时标注“请充电”，实际充电中显示闪电及“充电中”。短按物理PWR键切换熄屏/亮屏，熄屏时触摸无操作且不能唤醒；CPU和界面暂停，定时短暂唤醒补算自然成长/饱食并检查PWR。明暗数值规则见 [低功耗说明](low-power.md)。规则及接口见 [电量及熄屏说明](power.md)。

## 硬件与实现范围

设备官方规格为 466 × 466 触摸 AMOLED、32 MB Flash、8 MB PSRAM，并带有 QMI8658 六轴传感器和音频器件。[Waveshare 官方文档](https://docs.waveshare.com/ESP32-S3-Touch-AMOLED-1.75C)

游戏通过 ESP-IDF、板级支持组件和 LVGL 在设备上运行。触摸是本版的游戏输入，角色和界面由本地绘图代码生成，无需网络、浏览器、手机或在线模型参与核心循环。主机预览复用固件的模型与绘图代码；主机结果不能代替触摸屏、Flash 存储和实际功耗的实机验证。

存档需覆盖成长、饱食、星星、心愿进度、装扮所有权、当前装扮及奖励冷却，并兼容 0.3 的旧存档。新版格式迁移应保留原有宠物进度。普通固件升级不能擦除宠物存档分区。开心和吃饭动画、小游戏进行中的目标和连击不属于长期存档。

角色睡觉动画独立于系统熄屏。系统熄屏进入Light-sleep，明暗自然成长和饱食速率由物理显示状态决定。六轴体感、麦克风输入、语音识别、联网校时和离线时长补算尚未接入玩法。

## 后续扩展方向

| 扩展 | 具体玩法 | 实施前需要验证 |
|---|---|---|
| 拖拽喂食 | 把食物从碗拖到嘴边，进入吞咽动画 | 小屏手指遮挡、触摸坐标稳定性、手势取消 |
| 触控优化 | 在已实现的多击/长按/滑动基础上加入更细的身体分区反馈 | 真机手指遮挡、触摸精度与手势距离 |
| 六轴体感 | 倾斜设备控制小猫接星星 | IMU 方向、静态校准、姿态噪声和更新率 |
| 声音扩展 | 在已有互动音效和BOOT静音基础上增加音量档位 | 扬声器听感、最大安全音量、静音恢复和功耗 |
| 更多成长分支 | 根据长期陪伴方式解锁不同外观 | 分支条件透明、已有存档迁移、资源预算 |
| 休眠优化 | 在当前Light-sleep基础上进一步降低外围器件消耗 | 实际电流、续航与屏幕恢复 |

优先把触摸命中、反馈速度、成长目标和存档稳定性打磨完整，再加入新的硬件输入。后续每项应有可复现的实机验收条件，避免仅靠功能名称扩大玩法。
