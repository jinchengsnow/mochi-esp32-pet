# MOCHI 0.4.1 验证记录 — 2026-10-29

本版本重新设计小猫形象，按羁绊Lv.1–10切换体型、毛色、颊毛、尾纹、额纹与光效，并增加升级星光和形象名称提示。形象由已有成长值推导，存档格式和游戏数值规则不变。

## 已完成

- **固件**：ESP-IDF5.5.5 / ESP32-S3构建通过，最终日志无编译warning/error。应用771,968字节，6MiB应用分区剩余88%；esptool校验checksum与validation hash有效。
- **十级形象**：使用同一份固件绘图与状态机渲染232帧。全部10个等级在待机、开心、进食和睡眠下均经实际LVGL绘制与状态断言，形象名称与等级对应。
- **装扮**：覆盖19种等级/装扮组合，并另外检查最高等级皇冠在最大开心跳跃、进食与睡眠中的位置。实际查看最终图片，皇冠与耳尖没有遮住成长条。
- **实时升级**：通过真实触摸事件从59成长提升到60成长，验证形象从奶团幼猫变为蜜桃小猫、出现进化提示，并在序列化/重新读取后保留正确形象。
- **界面回归**：角色、三个底部按钮、小游戏计分/冷却、心愿、星星结算及装扮购买/切换继续通过实际LVGL指针事件测试。
- **字库**：264个UI字符全部通过LVGL glyph lookup，无占位符。
- **模型与存档**：ASan/UBSan测试通过；保持0.4的小游戏、防重复领奖、成长封顶、冷却、商店、48字节v1迁移、80字节v2往返与损坏拒绝测试。

预览：`preview/evolution.png`、`preview/evolution-states.png`、`preview/evolution-crown-states.png`、`preview/evolution-unlocked.png`。十级清晰全屏图为 `preview/level-01.png` 至 `preview/level-10.png`。

日志：`build-verification-0.4.1.log`、`model-verification-0.4.1.log`、`preview-verification-0.4.1.log`、`image-info-0.4.1.txt`。0.4.0的记录保留在 `verification-0.4.0.md`。
