# MOCHI 0.8.0 验证记录 — 2026-10-30

本版增加14种合成互动音效、BOOT物理键静音/恢复、声音偏好持久化、主页声音图标和非阻塞ES8311输出。保留0.7.0作息/待机、触控、低功耗、明暗倍率和v3存档。

## 软件验证

- ESP-IDF5.5.5 / ESP32-S3构建通过，最终日志无编译warning/error。应用849,424字节，6MiB应用分区剩余86%；esptool版本字段0.8.0，checksum与validation hash有效。
- ASan/UBSan共9组测试通过，保留模型、存档、电量、PWR、时间、触控和作息回归；新增BOOT与音频两组。
- BOOT检查30ms边界、按下/松手抖动、长按不重复、上电已经按住时首次释放不切换、32位计时回绕。设备轮询使用单调时钟，不依赖暂停的LVGL时间。
- 14种PCM检查非静音能量、最大6500峰值、直流偏移限制、首尾为0、整段和分块输出一致、无效类型/空缓冲/超出末尾保护。每段65–700ms，22050Hz单声道16位。
- 真实LVGL指针事件检查单击延迟后才发声、重复摸摸不绕过成长冷却、三击不混入单/双击音效、长按、左右逗猫、击掌、喂食、进食期间无额外音效、开局、正确命中和奖励。
- 静音后仍有动作和成长，BOOT不改变饱食/成长；熄屏期间切换BOOT不亮屏、不播放开启确认音；音频不可用时玩法继续。主机夹具观察生产UI提交的音效请求，不模拟扬声器实际输出。
- 同代码渲染418帧、347个UI字符glyph lookup通过。实际查看声音开启/静音/错误三种状态，以及低于10%电量时的顶栏：电量、时间、声音图标无重叠，圆屏内可见。
- `scripts/audio_preview.sh`从生产合成器导出14个WAV供离线试听，不作为固件内置大音频资源。

日志：`build-verification-0.8.0.log`、`model-verification-0.8.0.log`、`preview-verification-0.8.0.log`、`image-info-0.8.0.txt`。此前作息版本保留在 [0.7.0验证记录](verification-0.7.0.md)。

## 驱动与保存范围

音频任务只使用I2S TX，固定22050Hz/16bit/mono格式；不创建RX或初始化麦克风。每次播放结束后关闭DAC、功放和I2S，熄屏先取消音效、等待停稳和设置提交，再睡眠。GPIO0低电平可临时唤醒CPU处理BOOT，显示仍只由PWR恢复。

声音偏好单独保存在 `pet_nvs` 的 `audio/sound_on`，不修改v3宠物记录。初始化或播放失败会标记音效不可用，养成继续；设置保存错误会记录日志，不擦除已有数据。
