# 小猫触控互动 — 0.6.0

触控手势从主页的小猫区域开始。底部追星、喂食、睡觉按钮及顶部成长页入口继续保留。

| 手势 | 玩法 | 动画与反馈 |
|---|---|---|
| 单击 | 摸头 | 轻轻点头、闭眼微笑、爱心 |
| 双击 | 玩耍 | 进入15秒追星小游戏，沿用饱食成本、奖励与冷却 |
| 三击 | 挠肚皮 | 左右扭动、张嘴笑、摇尾和挥爪 |

| 左滑或右滑 | 逗猫 | 逗猫棒出现在对应方向，小猫转头看、抬爪去抓 |
| 上滑 | 击掌 | 举起肉垫小爪，配星光反馈 |

## 如何区分手势

单击、双击会等待末次松手后约320ms再判定，三击在第三次松手时判定。前面的单击或双击不会提前执行，因此双击不会先获得摸头奖励，三击也不会误开小游戏。触摸时先出现小光圈，表示已经收到输入。

每次按压移动不超过16像素且不足650ms可视为轻点；保持650ms触发一次抱抱。左右或向上滑动至少60像素、主方向明显时，在松手后触发动作。小幅拖动、下滑和明显对角线不会误判成轻点；向外拖动再回到原点也不会补发点击。

四击及以上的连续快速点击按前三击触发一次挠肚皮，后续点击等待320ms空隙后才开始新一组。长按松手不追加摸头；按住不放也不会反复领取奖励。

## 养成奖励

摸头、挠肚皮、抱抱、逗猫和击掌共用原有陪伴奖励：首次及每累计5分钟最多获得1点成长。没有冷却的动作仍会播放动画；切换手势不会额外刷新冷却。这些动作获得陪伴奖励时，都可记入“陪伴心愿”的摸摸项目。

双击玩耍沿用追星游戏规则：至少10饱食才可开始，入场消耗5饱食，结束后冷却60秒，按命中数奖励。双击本身不发摸头成长。进食时会提示等待，不会重启饭菜动画或重复结算。

亮屏/低功耗自然成长与饱食变化保持0.5.0规则，手势奖励在自然成长之外结算。

## 中断和兼容

按喂食/睡觉按钮、打开成长页或切换PWR屏幕状态会取消尚未判定的手势，避免晚到的摸头。熄屏仍禁用触摸；PWR亮屏后等待手指松开，熄屏前的连击不会恢复。

手势识别在 `main/pet_touch.c`，不依赖LVGL；UI通过真实按下、持续按压和松手事件驱动识别。表情和姿态是短期状态，沿用v3存档，不增加永久字段，也不改变旧宠物成长、装扮或冷却。

## 验证

已通过ASan/UBSan手势与模型测试，以及真实LVGL指针事件的单/双/三击、长按、左右/上滑、四击尾部抑制、共享奖励与菜单/喂食/PWR中断检查。构建和预览通过。本版本尚未烧录实机，实际手指连击节奏、滑动距离和长按体验需在触摸屏上确认。
