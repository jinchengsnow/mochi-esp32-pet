# 电量图标与物理按键熄屏 — 0.5.0

主页顶栏仅显示电池图标和状态，已移除屏幕上的熄屏按钮。存档状态位于最下方。

| 条件 | 显示 |
|---|---|
| 有效电量，未充电，至少10% | 电池图标和82%等百分比，填充量随电量变化 |
| 有效电量低于10%，未充电 | 粉红色电池图标与“9% 请充电”等标注 |
| 已在充电 | 电池图标叠加闪电，“9% 充电中”等标注；低于10%仍用粉红色 |
| 未检测到电池 | 图标内叉号和“未装电池” |
| 读取失败、电量计未启用或百分比无效 | 图标内横线和“电量 --”；有充电状态时显示“充电中 --” |

10%不触发低电量标注；0%是有效低电量。电量约每5秒读取一次，不把读取失败或未装电池显示成0%。图标使用LVGL基础图形绘制。

## PWR键切换显示

**短按侧面PWR键熄屏，再次短按PWR键亮屏。** 在主页、成长页或小游戏中都有效。屏幕没有用于熄屏或亮屏的触摸按钮。

熄屏将AMOLED亮度设为0、覆盖全黑画面并禁用LVGL触摸输入处理；触摸不会唤醒，也不会摸摸、喂食、命中星星或点击菜单。PWR亮屏后，触摸重新启用，但会等待手指松开，防止将熄屏期间按住屏幕的动作当作新的操作。

熄屏期间进入保留内存的Light-sleep，暂停CPU和界面，每500ms短暂检查PWR并按实际经过时间结算饱食和成长，定期保存；显示恢复为65%亮度，并恢复原页面。明暗速率和流程详见 [低功耗说明](low-power.md)。BOOT键不承担熄屏功能；PWR长按不作为显示切换事件，固件不改写原有长按关机配置。

## 按键实现

PWR通过板载AXP2101的POWERON短按事件接入，不当作ESP32 GPIO直接读取。依据 [官方原理图](https://files.waveshare.com/wiki/ESP32-S3-Touch-AMOLED-1.75C/ESP32-S3-Touch-AMOLED-1.75C-schematic.pdf)及 [X-Powers AXP2101数据手册](https://files.waveshare.com/wiki/common/X-power-AXP2101_SWcharge_V1.0.pdf) 第24、34–35页：

- 0x41 bit3启用POWERON短按事件，以读改写方式保留其他中断使能。
- 0x49 bit3为短按状态，以仅写入0x08的W1C方式确认，保留其他状态位。
- 启动时清除遗留短按，避免开机立即熄屏；确认成功才投递事件，避免同一锁存事件反复切换。
- 亮屏约100ms轮询按键、电量约5秒读取一次；低功耗期间暂停普通循环，每500ms定时唤醒检查按键。I2C失败不会制造按键事件；设置失败时后台重试。
- 后台将短按放入计数器，LVGL定时器消费事件并切换屏幕，不跨线程操作UI。

`main/pet_power_key.c`实现可移植寄存器协议；`main/pet_device.c`适配I2C和屏幕亮度；`main/pet_ui.c`处理显示、触摸启停和电池图标。

## 电量读取

继续复用BSP的I2C总线和0x34设备地址：0x00 bit3/bit5读取电池存在/USB有效；0x01 bits6:5读取充电方向；0x18 bit3检查电量计；0xA4读取百分比。地址方式依据 [Waveshare官方示例](https://github.com/waveshareteam/ESP32-S3-Touch-AMOLED-1.75C/tree/main/examples/esp-idf/01_AXP2101)。不修改充电参数、供电轨或电量计参数。
