# MOCHI 0.5.0 验证记录 — 2026-10-30

本版本在0.4.4基础上加入熄屏Light-sleep和明暗两种时间养成速率，保留PWR控制、熄屏触摸禁用、电量图标及启动SPI显示锁修复。本版本尚未在本次刷入实机。

## 软件验证

- ESP-IDF5.5.5 / ESP32-S3构建通过；最终编译无warning/error。应用788,640字节，6MiB应用分区剩余87%；esptool checksum和validation hash有效。
- ASan/UBSan时间养成测试通过：亮屏一小时饱食−12/成长+6、熄屏一小时饱食−2/成长+1，500ms分段与整段结算一致。
- 保留未满周期的进度：明暗混合、快速反复切换、32位tick回绕、暂停UI时钟后重锚、64位超长时间、饱食下限和成长上限通过。
- 小游戏跨休眠到期只结算一次，冷却按真实时间经过；游戏奖励不混入自然成长，临近600成长时按时间顺序结算。
- v3存档80字节往返，独立v1/v2夹具迁移通过；旧饱食计时按比例转换，自然成长计时从0开始。v3/v2全部单比特损坏、v1全部单比特损坏、截断与数值范围拒绝测试通过。
- 现有游戏、心愿、商店、PWR协议、电池边界、十级形象和装扮回归通过。
- 真实LVGL指针事件测试通过，包括熄屏触摸无操作、物理PWR恢复、按住手指亮屏的保护，以及暂停UI时钟补算一小时后的正确数值；恢复亮屏不会重复补算。
- 273个UI字符无占位符，渲染243帧，实际查看 `preview/time-rates.png` 的一小时对比。主机低功耗与电池由夹具模拟，使用生产模型和UI代码。

日志：`build-verification-0.5.0.log`、`model-verification-0.5.0.log`、`preview-verification-0.5.0.log`、`image-info-0.5.0.txt`。此前0.4.4记录保留在 `verification-0.4.4.md`。

## 低功耗实现审查

由电源工作线程在显示锁外暂停LVGL和其tick定时器，结清并等待存档后调用 `esp_light_sleep_start()`。通过500ms定时唤醒读取PMIC短按锁存；原理图无AXP_IRQ到ESP32 GPIO的直接连接，未虚构GPIO唤醒路径。休眠计时使用单调微秒差，并保留小于1ms的余数。

休眠前、休眠每5分钟及退出时保存。暂停、存档等待、休眠接口或低功耗期间PWR读取失败时，记录错误并恢复显示。恢复亮度仍由原LVGL线程在显示锁内执行，保持0.4.4已修复的SPI串行控制。

## 待实机验证

实际Light-sleep进入/退出、CPU睡眠驻留、电流/续航、PWR按键响应、USB连接影响、长时间稳定性、NVS断电和多次休眠恢复尚未测量。0.4.4的实机验收不能代替0.5.0低功耗验收。

可在更新后对照 `Low power exit` 日志中的sleep_cycles/rest_ms，确认休眠调用成功并核对角色变化，再用实际电流测量评估节能。完全断电/整机关机的时长仍暂停，不猜测离线时间。
