## 存档和烧录边界

分区布局保持0.3不变：启动器0x0、分区表0x8000、应用0x10000（6MiB）、独立pet_nvs在0x610000（64KiB）。发行包刷写映射只有启动器、分区表和应用，不包含NVS镜像。固件保留两份记录交替提交的机制。

v1迁移保留旧字段，新增字段初始化为零。局内成绩为临时状态；中途重启后不发未结算奖励，按最近成功存档保留入场消耗和剩余冷却。与此前版本一样，突然断电可能丢失尚未成功提交的修改；未进行真实Flash提交瞬间断电故障注入。
