## 分区与存档

| 地址 | 内容 |
|---|---|
| 0x0 | 启动器 |
| 0x8000 | 分区表 |
| 0x9000 / 0x6000 字节 | 原有默认 nvs，地址不变 |
| 0x10000 / 0x600000 字节 | 应用，地址与容量不变 |
| 0x610000 / 0x10000 字节 | 新增独立 pet_nvs |

刷写映射仍只有启动器、分区表和应用三个区域，固件升级不写 `pet_nvs`。应用使用独立命名空间、两个交替记录、明确版本、CRC32 和范围校验；没有自动擦除或重置失败存档的路径。
